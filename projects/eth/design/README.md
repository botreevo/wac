# design

One numbered document per direction, as in wac's own `design/`: what we are aiming at, the decisions taken with
their reasons, the order of work, and a state of play kept current. wac's `design/README.md` says what belongs in
one and how to write it; the same rules hold here.

These came from wac when the Ethereum packages left it (2026-11-09) and keep wac's numbers, so a reference to
"0003" in a commit message or a comment written before the move still finds them. A new one takes the next free
number above 1000, so the two sequences cannot collide.
