# issues

As in wac's tracker: an issue is something actionable that is not already written down, one file each, in
`open/` or `closed/`. wac's `issues/system/README.md` says when to file one and how; the same rules hold here.

The ones under `system/` came from wac when the Ethereum packages left it (2026-11-09) and keep wac's numbers, so
"0066" still means the light client's. wacuum's own issues are in `packages/wacuum/issues/`, as they were. **A new issue
here takes the next free number above 1000**, so it cannot collide with a number wac goes on to use.
