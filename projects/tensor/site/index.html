wac-tensor

Tensors, gradients, layers and optimizers in wac — TensorFlow's capabilities with an API started again from scratch — on a CPU backend that runs anywhere wac does and a WebGPU backend in the browser. Everything on these pages is wac compiled to WebAssembly; the only JavaScript is wac's own page host.

Draw a digit

A small convolutional network, trained on MNIST to 98.6% on the test set, reads what you draw — on your GPU through WebGPU, or the CPU without it.

CPU vs GPU

The same work timed on both backends in your browser: matrix products, digit inference and training, and a tiny GPT.

What's in the library

  • Tensors in f32 and f16, NumPy broadcasting, elementwise maths, reductions, batched matrix products, slicing and joining.
  • Convolution and pooling, NHWC as TensorFlow lays it out, and the transpose of a convolution.
  • Gradients of anything built from those — including gradients of gradients — every rule checked against finite differences.
  • Layers: dense, conv, embedding, dropout, layer and batch norm, multi-head attention, transformer blocks.
  • Optimizers: SGD, momentum, RMSProp, Adagrad, Adam and AdamW; checkpoints that save and load weights.
  • Two backends that agree: every GPU kernel is checked against the CPU on the same numbers, in both precisions.
Source: git.voltrevo.com/wac-tensor. MNIST from Yann LeCun's dataset, via Google's mirror.
